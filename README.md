# ⚡ Calculadora de Consumo de Energia

## 📌 Sobre o projeto
Este projeto é uma calculadora em Python que estima o consumo mensal de energia elétrica de um aparelho, com base na potência e no tempo de uso diário.

## 🎯 Objetivo
Ajudar usuários a entenderem quanto seus aparelhos consomem de energia e o custo aproximado mensal.

## 🛠️ Tecnologias
- 🐍 Python  
- 💻 VS Code  
- 🌐 GitHub  

## 🧮 Fórmula utilizada
consumoMensal = (potencia * horasDia * 30) / 1000

## 💰 Cálculo de custo
custo = consumoMensal * 0.75

## ▶️ Como executar
1. Baixe o projeto  
2. Abra no VS Code  
3. Execute: python app.py

## 📊 Exemplo
1. Aparelho: Geladeira
2. Consumo estimado: 45 kWh/mês
3. Custo estimado: R$ 33.75
